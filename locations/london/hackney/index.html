Loft conversions and extensions in Hackney

Director-led. Fixed fees in writing. A reply within one working day.

Hackney homeowners search for loft conversions, side-returns and wrap-arounds on Victorian terraces in Stoke Newington, De Beauvoir, Clapton, Homerton and London Fields. The stock is robust. The planning is not casual — especially where a new Residential Extensions SPD and conservation-area character appraisals set the rules of the roof.

Mansards and rear dormers are the schemes we see refused most often: too tall, too wide, low-quality uPVC, or a previous HMO conversion muddying the use. We design the roof as part of the house, coordinate structure early, and write a short planning statement that answers the actual policy, not a generic template.

If Hackney has already refused the application, that is still a project. The decision notice is a brief. We tell you which reasons are design, which are use, and which are missing information — then we only redraw what changes the outcome.

Fees are fixed and in writing. A director replies within one working day.

Questions

Does a loft conversion in Hackney need planning permission? Many do, particularly mansards, hip-to-gable changes on end terraces, and anything in a conservation area. We check PD rights, the SPD and the street before we draw.

Can the studio take on a refused Hackney application? Yes. Send the ref and the decision. We will say if a resubmission is realistic before you spend more money.

Does the studio work only in Hackney? No. Hackney is a core borough alongside Camden and Islington. The studio is in Shoreditch, on Paul Street.
